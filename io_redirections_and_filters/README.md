# Shell, I/O Redirections and Filters

This project covers basic Bash commands, standard input,
standard output, redirections, and filters.

## Scripts

- 4-lastlines: Displays the last 10 lines of /etc/passwd.
- 5-firstlines: Displays the first 10 lines of /etc/passwd.
- 6-third_line: Displays the third line of the file iacta using head and tail.
- 7-file: Creates a file with a special-character filename containing Best School followed by a newline.
- 8-cwd_state: Saves the output of ls -la to ls_cwd_content, overwriting existing content.
- 9-duplicate_last_line: Duplicates the last line of the file iacta using tail and append redirection.
- 10-no_more_js: Deletes all regular .js files in the current directory and its subdirectories.
- 11-directories: Counts directories and subdirectories, including hidden directories, excluding the current directory
- 12-newest_files: Displays the 10 newest directory entries, sorted by modification time..
- 13-unique: Sorts input words and displays only those appearing exactly once
- 14-findthatword: Displays all lines containing root from /etc/passwd..
- 15-countthatword: Counts the number of lines containing the pattern bin in /etc/passwd.
- 16-whatsnext: Displays lines containing root and the following three lines from /etc/passwd.
- 17-hidethisword: Displays lines from /etc/passwd that do not contain the pattern bin.
- 18-letteronly: Displays lines from /etc/ssh/sshd_config that begin with an uppercase or lowercase letter.
- 19-AZ: Replaces uppercase A with Z and lowercase c with e using tr.
- 20-hiago: Removes all uppercase C and lowercase c characters from standard input.
- 21-reverse: Reverses the characters in each line of standard input.
- 22-users_and_homes: Displays usernames and their home directories from /etc/passwd, sorted alphabetically.
