# Shell, init files, variables and expansions

This project explores Bash variables, environment variables,
aliases, expansions, and shell arithmetic.

## Scripts

- 0-alias: Defines an alias named ls that expands to rm *.
- 1-hello_you: Prints hello followed by the current Linux username using the USER environment variable.
- 2-path: Appends /action to the PATH environment variable.
- 3-paths: Counts the number of directories in the PATH environment variable.
- 5-local_variables: Lists shell variables, environment variables, and shell functions.
- 6-create_local_variable: Creates a local Bash variable named BEST with the value School.
- 7-create_global_variable: Creates and exports the BEST environment variable with the value School.
- 8-true_knowledge: Prints the value of TRUEKNOWLEDGE plus 128.
- 9-divide_and_rule: Divides the value of POWER by DIVIDE and prints the result.
- 10-love_exponent_breath: Calculates BREATH raised to the power of LOVE.
- 11-binary_to_decimal: Converts the binary value stored in BINARY to decimal.
- 12-combinations: Prints all alphabetically ordered two-letter combinations except oo.
- 13-print_float: Displays the value of NUM formatted to two decimal places.
- 14-decimal_to_hexadecimal: Converts the decimal value stored in DECIMAL to lowercase hexadecimal.
